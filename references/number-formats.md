# 号码变体与判定顺序（实测穷举）

以下全部来自真实数据，不是设想。写解析前对着这张表逐条覆盖，能避免绝大多数漏号与误判。

## 归一化

```python
FW = str.maketrans('０１２３４５６７８９', '0123456789')   # 全角数字
PUNCT = '（）()【】[]。，,.、:：;；"\'“”‘’!！?？·~—_-'

def norm(s):
    s = str(s).translate(FW)
    s = re.sub(r'[\s\u3000]', '', s)      # 含全角空格
    return s.strip(PUNCT)
```

## 判定顺序（顺序错了必然误判）

```
1. 全角转半角 → 去空白 → 剥首尾标点
2. 纯 11 位且 1[3-9] 开头              -> 手机号
3. 纯数字但位数不对                     -> 手机号 + 异常备注
4. 剥掉中文标记（微信|微|号|同号）的首尾
5. 无 11 位手机号 且 含汉字             -> 正文，跳过     ← 必须在字母判定之前
6. 含拉丁字母                           -> 微信号
7. 含 11 位手机号                       -> 手机号 + 备注记录被剔掉的修饰词
8. 其余                                 -> 跳过
```

### 两个顺序陷阱

- **第 5 步不能省**：`明天发201B，还有气驱模块`、`你抖音 yk201柴油车氮氧超标` 含字母但纯属正文，
  不先拦掉就会被判成微信号。
- **第 6 步必须早于第 7 步**：`微信tonghao13800138014`、`v13800138015` 同时含字母和数字串，先判字母才对。

```python
CJK = re.compile(r'[\u4e00-\u9fff]')
MOBILE = re.compile(r'1[3-9]\d{9}')
MARK = r'(?:微信|微|号|同号)'

def classify(raw):
    t = norm(raw)
    if not t:
        return None
    if re.fullmatch(r'1[3-9]\d{9}', t):
        return ('phone', t, '')
    if t.isdigit():
        return ('phone', t, '仅 %d 位，非 11 位手机号，待核对' % len(t))

    t2 = re.sub(r'^%s+' % MARK, '', t)
    t2 = re.sub(r'%s+$' % MARK, '', t2).strip(PUNCT)
    if not t2:
        return None
    if not MOBILE.search(t2) and CJK.search(t2):     # 第 5 步
        return None
    if re.search(r'[A-Za-z]', t2):                   # 第 6 步
        note = '原文「%s」' % raw if t2 != t else ''
        if t2[:1] in 'Qq' and t2[1:].isdigit():
            note = '原文「%s」；Q 开头且为纯数字，疑为 QQ 号，待确认' % raw
        return ('wechat', t2, note)
    m = MOBILE.search(t2)                            # 第 7 步
    if m:
        extra = (t2[:m.start()] + t2[m.end():]).strip(PUNCT)
        note = ('原文「%s」；修饰词「%s」已剔除' % (raw, extra)) if extra else (
               '原文「%s」；中文标记已剔除' % raw if t2 != t else '')
        return ('phone', m.group(0), note)
    return None
```

## 去重与日期

- 同一号码只留一行，**日期取最早一次出现**
- 号码若已归属某实名客户行 → 不再单独成行，把该客户的日期提前到更早的那次

## 为什么「纯数字 → 手机号」而不是微信号

微信 ID 必须以字母开头，**不可能是纯数字**。所以剥掉「微 / 微信」标记后剩下 11 位纯数字的，
只能是他的手机号（哪怕原文用「微」标注，那意思也是「微信号就是这个手机号」）。
这条推理是整套判定规则的地基。
