# wechat-customer-extract

> 从微信聊天记录导出文件（WeFlow 格式）中提取客户台账：联系方式、地区、购买设备。

一个 [WorkBuddy](https://www.workbuddy.cn) Agent Skill，也可以当纯粹的 Python 工具库用。

## 解决什么问题

微信里做生意的人都有这个场景：客户信息散落在几十个聊天窗口里——手机号、微信号、收货地址、买了什么设备，全在聊天记录里。想整理成一张表，手工抄几百条不现实，写个正则又到处都是坑。

这个技能把踩过的坑固化成流程：**哪些能自动化、哪些必须人工、哪些顺序不能错**。

## 核心结论（最值钱的部分）

### 1. 手机号可以自动化，姓名和设备不行

11 位手机号的正则是可靠的。但抽姓名会串位，实测：

| 原文 | 正则抽出 | 正确 |
|---|---|---|
| `山西省忻州市某街某汽修厂13800138023李四` | 东汽修厂 | 李四 |
| `河北省唐山市滦南县某路东某车场王五13800138022` | 场王五 | 王五 |
| `浙江省杭州市余杭区…` | 城市「江省杭州市」 | 杭州市 |

**正确做法是三段式**：脚本粗抽 → 打印全部原文 → 人工逐条比对写死常量表 → 脚本只负责写入。

40 条约十几分钟，90 条约半小时。比继续调正则快得多，也准得多。

### 2. 微信号不可能是纯数字 —— 这是整套判定规则的地基

微信 ID 必须以字母开头。所以剥掉「微 / 微信」标记后剩下 11 位纯数字的，**只能是手机号**——哪怕原文用「微」标注，意思也是「微信号就是这个手机号」。

### 3. openpyxl 有个静默的坑

```python
ws.cell(row, col, value=None)   # ❌ 不会清空已有单元格
ws.cell(row=r, column=c).value = v   # ✅ 这样才会
```

源码逻辑是 `if value is not None: cell.value = value`。用「加载已有文件 → 部分覆盖 → 保存」的重跑模式时，陈旧数据会残留，表现为**行错位、号码莫名重复**。要么每次从干净模板重建，要么显式赋值。

### 4. 判定顺序不能调换

```
1. 全角转半角 → 去空白 → 剥首尾标点
2. 纯 11 位且 1[3-9] 开头        -> 手机号
3. 纯数字但位数不对               -> 手机号 + 异常备注
4. 剥掉中文标记（微信|微|号|同号）首尾
5. 无手机号 且 含汉字             -> 正文，跳过    ← 必须在字母判定之前
6. 含拉丁字母                     -> 微信号
7. 含 11 位手机号                 -> 手机号
```

第 5 步不省：`明天发201B，还有气驱模块` 含字母但纯属正文，不先拦会被判成微信号。

## 使用

### 作为 WorkBuddy 技能

把整个目录放到 `~/.workbuddy/skills/wechat-customer-extract/`，之后提到「把聊天记录整理成客户表」就会自动加载。

### 作为 Python 工具库

```bash
pip install openpyxl
```

```python
import sys
sys.path.insert(0, 'scripts')
from parse_messages import load_chat, classify, parse_region, collect_contacts, verify

meta, msgs = load_chat('群聊_发货对接群.xlsx')
print(meta)                       # {'wxid': ..., 'nick': ...}
print(len(msgs), '条消息')

# 归一化 + 分类单个 token
print(classify('微13800138019'))   # ('phone', '13800138019', '原文「微13800138019」；中文标记已剔除')
print(classify('v13800138021'))    # ('wechat', 'v13800138021', '')
print(classify('明天发201B，还有气驱模块'))  # None（正文，正确跳过）

# 从一段地址抽省市（只认原文写出的，不反推）
print(parse_region('浙江省杭州市余杭区某路1号'))   # ('浙江省', '杭州市')
print(parse_region('西安市灞桥区某路'))           # ('', '西安市')

# 批量收集联系方式（去重，日期取最早）
rows = collect_contacts(msgs, sender='我')

# 回读校验：行数 / 重复号码 / 缺号码 / 逐列填充
verify('客户信息收集表.xlsx')
```

### 生成空白台账模板

```bash
python scripts/build_table.py ./客户信息收集表.xlsx "客户信息收集表"
```

产出三个 sheet：`客户信息`（10 列主表，含序号公式、条件格式、冻结筛选）、`填写概览`（KPI 全公式联动）、`填写说明`。

## 数据安全

仓库内所有示例数据均为**脱敏占位数据**（手机号统一为 `1380013xxxx`，姓名与商号为通用代称）。请勿把真实客户数据提交到公开仓库。
